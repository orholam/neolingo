# Duolingo Clone

A modern, responsive Duolingo clone built with Vite, React, and Tailwind CSS.

## Features

- 🎨 Beautiful, Duolingo-inspired UI design
- 📱 Fully responsive layout
- 🎯 Interactive language learning lessons
- 💚 Heart system (lives)
- 💎 Gem/XP tracking
- 📊 Progress tracking
- 🌍 Multiple language selection

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

The app will be available at `http://localhost:5173`

### Build

```bash
npm run build
```

## Pages

- **Landing Page** (`/`) - Login/Signup interface
- **Home Page** (`/home`) - Language selection and dashboard
- **Lesson Page** (`/lesson`) - Interactive language learning exercises

## Tech Stack

- **Vite** - Fast build tool and dev server
- **React** - UI library
- **React Router** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework

## Project Structure

```
src/
  ├── pages/
  │   ├── Landing.jsx    # Login/Signup page
  │   ├── Home.jsx       # Dashboard with language selection
  │   └── Lesson.jsx     # Interactive lesson interface
  ├── App.jsx            # Main app component with routing
  ├── main.jsx           # Entry point
  └── index.css          # Global styles with Tailwind
```
